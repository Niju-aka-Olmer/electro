# Изображения схем расключения

Имена файлов должны соответствовать id схем из `src/data/wiring-schemes.tsx`:

## Обычные
- **single-switch.jpg** — Одноклавишный выключатель
- **two-key-switch.jpg** — Двухклавишный выключатель
- **three-key-switch.jpg** — Трёхклавишный выключатель

## Проходные
- **pass-through-2.jpg** — Проходной выключатель (2 точки)
- **pass-through-3.jpg** — Проходной + перекрёстный (3 точки)
- **pass-through-4.jpg** — Два перекрёстных (4 точки)
- **dual-pass-through.jpg** — Двухклавишный проходной
- **pass-through-5.jpg** — 5+ точек
- **dual-cross-pass.jpg** — Двухклавишный с перекрёстным

## Специальные
- **impulse-relay.jpg** — Импульсное реле
- **dimmer.jpg** — Диммер
- **switch-with-indicator.jpg** — Выключатель с подсветкой

## Автоматика
- **motion-sensor.jpg** — Датчик движения
- **twilight-switch.jpg** — Сумеречный выключатель

## Комбинированные
- **socket-switch.jpg** — Розетка + выключатель

Формат: JPG, рекомендуется ширина 800-1200px.
