# Changelog

Все изменения проекта в хронологическом порядке (от новых к старым).

---

## 2026-07-15

- **Авторизация пользователей**: NextAuth.js v5 + Credentials Provider (логин/пароль), bcrypt, JWT-сессии
- **PostgreSQL 16** на VDS, Prisma ORM (схема: User, SavedCalculation)
- **Страницы**: `/login` (вход/регистрация), `/dashboard` (личный кабинет — список, переименование, удаление расчётов)
- **API**: `/api/auth/register`, `/api/calculations` (CRUD), `/api/calculations/[id]`
- **Кнопка входа** в header главной страницы
- Плашки «В разработке» на страницах «Щиток», «Схемы», «AI-консультант»
- Страница «Отказ от ответственности» (7 разделов), ссылка в футере и меню
- Мобильное меню: React Portal, inline-стили, без transform/backdrop-filter (iOS Safari fix)

## 2026-07-14

- **Деплой на VDS**: проект развёрнут на Ubuntu 24.04 (Beget), домен `electro.asod.su`
- Настроен Nginx как reverse proxy (80 → 3000, редирект на HTTPS)
- SSL-сертификат через Let's Encrypt (certbot)
- PM2 для управления процессами Next.js, автостарт при ребуте
- UFW: порты 22, 80, 443
- Добавлены `*_key*` и `*.pem` в `.gitignore`

## 2026-07-02

- Исправлены пояснения в расчёте: везде 30мА вместо 10мА, добавлены ссылки на ПУЭ (п. 7.1.82) и ГОСТ Р 50571.3-2009
- Добавлена полотенцесушилка в список мощных потребителей (600 Вт, 10А)
- Тёплый пол теперь с вводом квадратуры (150 Вт/м²), мощность рассчитывается динамически
- Исправлено описание характеристики вводного автомата C→B согласно требованиям Ростехнадзора
- Полная адаптация под мобильные устройства: viewport meta, гамбургер-меню, адаптивные шрифты/отступы/grid, скролл таблиц и щитка
