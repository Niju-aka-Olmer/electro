# ElectroPlan — Project Overview

## 🎯 Описание проекта

**ElectroPlan** — интерактивный веб-консультант по электрике жилых помещений.
Пользователь описывает своё помещение (квартира / дом), количество комнат, нагрузки —
и получает полный расчёт: автоматы, УЗО, дифавтоматы, схемы расключения коробок,
расчёт модульного шкафа.

## 🧑‍💻 Целевая аудитория

| Сегмент | Потребность |
|---------|------------|
| Самостройщики | Сделать проводку самому без электрика |
| Прорабы / бригадиры | Быстро прикинуть материалы |
| Хозяева квартир | Понять, что делает электрик, проверить смету |
| Студенты-электрики | Учебные схемы |

## ✨ Ключевые фичи

### 1. 🔌 Калькулятор автоматики
- Ввод: тип помещения, площадь, кол-во розеток/групп, мощности приборов
- Вывод: список автоматов (номинал, кол-во), УЗО / дифавтоматы с обоснованием

### 2. 📦 Расчёт щитка
- Подсчёт модулей (DIN-рейка)
- Рекомендация типа/размера щита (AP, UP, внешний/встроенный)
- Визуальная компоновка щитка

### 3. 🗺️ Схемы расключения
- Распределительная коробка на свет
- Распределительная коробка на розетки
- Проходной выключатель (2 точки)
- Перекрёстный выключатель (3+ точки)
- Интерактивные SVG-схемы с подписями

### 4. 💬 AI-консультант
- Текстовый ввод описания ситуации
- Ответ с конкретными рекомендациями (автоматы, схемы, материалы)
- DeepSeek API под капотом

### 5. 📋 Экспорт
- PDF-отчёт с расчётами и схемами
- Список материалов (BOM)

## 🎨 Дизайн-концепция

**Направление**: Industrial Precision — как приборная панель электростанции.
Тёмный фон с янтарными/оранжевыми акцентами (цвет предупреждения на электрооборудовании),
монопространственные шрифты для данных, технические сетки.

## 📐 Ограничения MVP

- Только 220В / однофазная сеть (Россия/СНГ)
- Жилые помещения (не промышленность)
- ГОСТ Р 50571 / ПУЭ 7
