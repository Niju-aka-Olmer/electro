# ElectroPlan — Project Overview

## 🎯 Описание проекта

**ElectroPlan** — интерактивный веб-инструмент для электромонтажных расчётов и визуализации электрического щитка. Пользователь описывает своё помещение (квартира / дом), выбирает нагрузки — и получает полный расчёт: автоматы, УЗО, дифавтоматы, компоновку модульного щитка.

## 🧑‍💻 Целевая аудитория

| Сегмент | Потребность |
|---------|------------|
| Самостройщики | Сделать проводку самому без электрика |
| Прорабы / бригадиры | Быстро прикинуть материалы |
| Хозяева квартир | Понять, что делает электрик, проверить смету |
| Студенты-электрики | Учебные схемы |

## ✨ Реализованные фичи

### 1. 🔌 Калькулятор автоматики ✅
- Ввод: тип помещения, количество комнат, розеточные группы, освещение
- Выбор спецнагрузок: электроплита, варочная панель, духовка, стиральная машина, посудомоечная машина, холодильник (16А), водонагреватель, кондиционер, тёплый пол, сауна, бойлер
- Выбор оборудования без автоматов: реле напряжения (2 модуля), розетка на DIN-рейку (2 модуля)
- Расчёт: вводной автомат, групповые автоматы, УЗО/дифавтоматы
- **Три стратегии защиты**: Эконом, Раздельный, Всё раздельно (индивидуальный диф на каждую линию)
- Приборы, связанные с водой — УЗО 10мА, влажные помещения — 10мА
- Автоматическое обоснование выбора по ПУЭ

### 2. 📦 Визуализация щитка ✅
- Реалистичная схема щитка на чистом HTML/CSS с drag-and-drop (@dnd-kit)
- Отображение шин L/N/PE, DIN-рейки, клемм подключения
- Групповые скобки для УЗО/дифов с подчинёнными автоматами
- Drag-and-drop устройств между рядами
- Выходные шины с подписями нагрузок
- Подсчёт модулей + 30% запас
- Выбор типоразмера щитка

### 3. 🗺️ Схемы расключения ⏳
- Заглушка, страница создана

### 4. 💬 AI-консультант ✅
- Чат со стримингом ответа через DeepSeek API
- Быстрые подсказки

### 5. 📋 Экспорт ⏳
- Кнопка печати (браузерная)

## 🎨 Дизайн-концепция

**Направление**: Электромонтажная тема. Тёмный фон с цветами проводки ANSI:
- Красный (#e74c3c) — фаза L
- Синий (#3498db) — ноль N
- Зелёный (#27ae60) — земля PE

## 📐 Ограничения

- Только 220В / однофазная сеть (Россия/СНГ)
- Жилые помещения (не промышленность)
- ГОСТ Р 50571 / ПУЭ 7
