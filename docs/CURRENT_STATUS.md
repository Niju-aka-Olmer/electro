## Реализованные модули

### 🔌 Калькулятор автоматики (реализован)
- Форма ввода параметров помещения (этажность, тип, фазы, вводной автомат)
- Добавление/удаление комнат с настройкой розеток, освещения, спецнагрузок
- Выбор готовых нагрузок из каталога (STANDARD_LOADS):
  - Электроплита, варочная панель, духовка, стиральная машина
  - Посудомоечная машина, холодильник (16А), водонагреватель
  - Кондиционер, тёплый пол, сауна, бойлер
  - Реле напряжения (2 модуля, без автомата)
  - Розетка на DIN-рейку (2 модуля, без автомата)
- Расчёт групповых автоматов (16А розетки, 10А освещение)
- Расчёт УЗО/дифавтоматов (групповые и вводное)
- **Стратегии защиты**: Эконом (1 диф на помещение), Раздельный (розетки/свет раздельно), **Всё раздельно** (индивидуальный диф на КАЖДУЮ линию)
- Все УЗО/дифавтоматы — 30мА (стандарт для жилых помещений, требование Роспотребнадзора)
- Вводной автомат — характеристика B (требование Роспотребнадзора)
- Расчёт вводного автомата по вводному току
- Вывод результатов с обоснованием по ПУЭ
- **Динамическое пояснение простым языком** — для каждого расчёта генерируется объяснение:
  почему выбран именно такой вводной автомат, зачем нужны УЗО/дифавтоматы,
  чем отличаются стратегии защиты
- **Экспорт в Excel (XLSX)** — скачивание сгруппированной спецификации (Наименование | Ед. | Кол-во)
  с полными названиями и реальными артикулами
- **Каталог производителей** — ABB и Dekraft, реальные артикулы подставляются автоматически
  - Автоматы: ABB SH201/S202 | Dekraft ВА-101
  - УЗО: ABB F202 | Dekraft УЗО-03
  - Дифавтоматы: ABB DSH201R | Dekraft ДИФ-103
  - Реле напряжения: WELROK d2-63 (единое для всех брендов)
  - Розетка на DIN-рейку: ABB M1175 / Dekraft РМ-01
- Список материалов (BOM)

### 📦 Визуализация щитка (реализована)
- Реалистичная схема электрического щитка на чистом HTML/CSS
- **Архитектура**: Enclosure → Row → Bus (L/N/PE) → Drops → DeviceCards → DIN-рейка → GroupBrackets → Out
- Drag-and-drop устройств через `@dnd-kit` (перетаскивание между рядами)
- Визуализация шин: L (красный #e74c3c), N (синий #3498db), PE (зелёный #27ae60)
- Вертикальные спуски (drops) к каждому устройству
- Клеммы подключения сверху и снизу каждого устройства
- Групповые скобки (GroupBrackets) для УЗО/дифов с подчинёнными автоматами
- Выходные шины N/PE с подписями нагрузок
- Реле напряжения и DIN-рейка розетка отображаются как модули в щите

**Константы визуализации:**
```
MOD = 56px     — ширина 1 DIN-модуля
CARD_H = 68px  — высота карточки устройства
BUS_H = 6px    — высота полосы шины
DROP_H = 32px  — высота спусков
OUT_H = 56px   — высота выходов
ROW_GAP = 12px — зазор между рядами
```

**Эволюция подходов к визуализации:**
1. Чистый CSS/SVG — первая версия
2. ❌ React Flow (@xyflow/react) — попытка, отказались из-за проблем с масштабом и линиями
3. ✅ Чистый HTML/CSS + @dnd-kit — текущая версия
